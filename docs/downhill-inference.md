# Downhill-mode replay evidence

The supported Global replay runner layout retains distance, lane, actual speed, HP, temptation mode and the front-blocking slot. The selected local capture has exactly 12 runner bytes per frame, with no unparsed runner tail, and events of types 3/4/5/6. It supplies no explicit downhill-mode or position-keeping-mode flag. This describes that selected format and parser evidence, not every possible game interface or future replay layout. The missing mode is not a missing JSON name that can be recovered by renaming a field.

`status-models.ts` seeds downhill-mode **candidates** when reference course geometry is downhill and observed net HP drain is below half the self-speed HP reference rate. Self speed removes resolved current-speed modifiers (types 21/22) while they are active. Resolved target-speed/acceleration skills (27/31) are allowed: their influence is already represented in observed self speed. A sampled speed fit then detects free exits and possible re-entry; a block does not itself end an established mode. A supplemental one-sample candidate can use a rise above the ordinary downhill target followed by a drop or the slope ending. That supplemental path uses speed evidence and is not independent confirmation of a causal speed benefit.

Recorded skill branches use shared `resolveSkillTiming` and `effectValue`. A type-9 HP event excludes only its touching retained-sample brackets, even if its replay duration is zero or contains a spare positive value. A combined heal/target skill likewise excludes the heal bracket while its resolved speed effect can coexist with later HP inference. Direct-speed onset/expiry brackets remain unassessed because retained velocity does not resolve a discontinuity. Unknown recipient masks, effect scaling, duration, active stat/lane effects and rushed/competition interactions still withhold the affected inference.

The supplemental speed fit also withholds candidates during an unknown own or potentially received proc. A mask excluding the runner can rule out an unknown foreign proc; a known same-team negative effect contributes zero under the reference immunity rule. These guards prevent an unresolved speed contribution from being mistaken for a one-sample downhill entry.

The HP reference is averaged at the retained velocity endpoints; its nonlinear within-bracket integral is approximate. Net HP includes simultaneous drain/recovery, and omitted events cannot be ruled out. Candidate boundaries remain sampled/model boundaries. Candidates retain `evidence: estimated`; a missing candidate never means the internal mode was off. Conditional mode factors are reference mechanics, not directly observed causal gains.

An authorized local replay now supplies a gate-1 candidate overlapping its recorded Professor of Curvature activation, with normalized HP ratio about 0.384. Other retained brackets yield ratios around 0.40–0.42. The original replay is unchanged and is not included in the public workflow.

Position-keeping candidates share the repaired bounded instant-HP handling, so an early zero-duration recovery no longer excludes all later samples. [Pace inference](pace-inference.md) now normalizes resolved movement skill offsets while excluding unknown inputs, blocking, start dash and unresolved rushed/competition context. Compatible velocity/HP and positional evidence is required; a speed rise alone does not identify a hidden mode.

`tests/downhill-workflow.ts` runs 18 synthetic whole-file import/reference/analysis cases: independent HP evidence, overlapping target/acceleration, reference-duration fallback, instant HP with zero/spare-positive duration, current-speed normalization with positive and negative controls, unknown scaling/masks/rushed flags, unsupported lane effects, low drain on flat ground, combined heal/target effects, and one-sample candidates with unknown procs, excluded recipients and known same-team immunity. Run `node --import tsx tests/downhill-workflow.ts <temporary-folder>`. All cases passed. No private replay is a test fixture.

Formula provenance remains in [effect-models.md](effect-models.md), [THIRD_PARTY_LICENSE.txt](../src/data/THIRD_PARTY_LICENSE.txt) and source comments. Readable simulator/mechanics evidence supplies the HP self-speed distinction and downhill 0.4 drain factor; this repair does not claim to have recovered the native downhill implementation.
